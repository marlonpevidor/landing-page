# Mentoria Educador Cristão Clássico

Landing page da mentoria do Prof. Marlon Pevidor.

- `index.html` — a página (HTML e CSS em um único arquivo, sem build)
- `assets/marlon.webp` — foto de perfil

## Publicar com GitHub Pages

1. No GitHub, abra **Settings → Pages** deste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Salve. Em um ou dois minutos a página fica em `https://marlonpevidor.github.io/landing-page/`.
